Nasıl çalışır

Seven steps, and it only ever asks you things a person would actually know.

01

Where are you going

Type any fragment. All 460 stations come out of the page in one call and get matched locally, so Turkish characters are optional and typos are fine: sogutlucesme finds SÖĞÜTLÜÇEŞME, ankra gets a “did you mean ankara?”.

02

Which day, or days

One if you are fixed, several if you are flexible. Type 17 18 21 and it watches all three. A day that already went past means next month.

03

Reads every train

Opens each one for every class with its own price and free seat count, because the results page shows only the cheapest and quietly hides that business is ₺465 more.

04

You choose

By row number or by departure time, because 08:23 is how you actually think about trains. Then the classes you would genuinely sit in.

05

It waits

One browser, one sweep every 45 to 90 seconds, randomised. A patient person, not a request flood.

06

It takes the seat

Class, Seçin, Devam Et, seat map, a free seat, bay/bayan, Seçimi Tamamla. A real hold on TCDD's side.

07

It wakes you up

Beeps until you answer and leaves the browser parked on your held seat. It never sweeps again, and it never touches your card.

Zor kısımlar

The parts that took the longest were never the parts that looked hard.

Seats are images, not classes

The map does not mark a free seat with a CSS class. It swaps the seat image, and that image is a base64 blob.

So instead of pasting a blob in the source, it finds the image that appears exactly as many times as the wagon button says are free. Self-calibrating, and it survives TCDD redrawing the icons.

A dropdown that closes itself

The station input is a data-toggle. Clicking it when the list is already open shuts it, and every option silently stops being clickable.

Fixed by only opening it when it is shut.

The same date, twice

The calendar renders two months side by side, and each repeats the other's spill-over days. The same data-date matches two cells and strict mode throws.

:not(.off) keeps it to one.

İ.lower() is not i

Python turns "İ".lower() into an i plus a separate combining dot, which matches nothing a person ever types.

Fold the Turkish letters flat first, lowercase after.

Cards that move

Track positions shift as the day's early departures leave, so gidis1 quietly becomes a different train.

Everything is keyed on departure time instead.

One accordion, one card

Scanning every train collapsed the one that had the seat, so the wagon button was no longer clickable when it mattered.

Re-open before grabbing.
