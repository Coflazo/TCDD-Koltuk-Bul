# TCDD Koltuk Bul

**Бот, який ловить місця, що звільнилися в розпроданих турецьких потягах, і одразу їх утримує.**

Він знову й знову перевіряє обрані вами рейси на сайті TCDD. Щойно хтось скасовує квиток,
бот обирає місце, запускає тимчасове бронювання TCDD і дзвонить будильником, доки ви не
підійдете до комп'ютера.

Працює по всій мережі, а не на одному напрямку: 460 станцій, в обидва боки, YHT, Anahat і
Bölgesel. Які є класи вагонів, він читає з самого потяга. Нічого з цього не вписано в код.

## Встановлення

Програмувати не потрібно. Достатньо одного рядка.

**macOS / Linux:**
```bash
curl -fsSL https://raw.githubusercontent.com/Coflazo/TCDD-Koltuk-Bul/main/install.sh | bash
```

**Windows (PowerShell):**
```powershell
irm https://raw.githubusercontent.com/Coflazo/TCDD-Koltuk-Bul/main/install.ps1 | iex
```

Куди встановиться: якщо ви на робочому столі, створить там теку. Якщо ви вже в теці
всередині робочого столу, встановиться просто там. Звідусіль інде перейде на робочий стіл.
Наприкінці лишиться файл для подвійного клацання: **Başlat.command** (macOS, Linux) або
**Baslat.bat** (Windows).

## Як користуватися

1. Введіть звідки й куди. Турецькі літери необов'язкові, друкарські помилки не заважають:
   `sogutlucesme` знайде SÖĞÜTLÜÇEŞME, а на `ankra` запропонує ANKARA.
2. Який день чи дні. Якщо ви гнучкі, наберіть `17 18 21`, і він стежитиме за всіма трьома.
3. Покаже всі потяги тих днів із цінами та кількістю вільних місць за класами.
4. Оберіть потяги й класи, якими ви справді поїдете.
5. Решта на ньому. Утримає місце й розбудить вас. Оплата за вами.
