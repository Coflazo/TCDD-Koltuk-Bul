# TCDD Koltuk Bul

**満席のトルコ鉄道でキャンセルが出た席を、その瞬間に押さえてくれるボットです。**

指定した列車を繰り返し確認します。誰かがキャンセルすると席を選び、TCDD の一時予約を開始し、
あなたがパソコンの前に来るまで鳴り続けます。

一路線ではなく全路線に対応しています。460 駅、上下線どちらも、YHT・Anahat・Bölgesel の
いずれも。どの등급があるかはその列車から読み取るため、路線も列車も等級もコードには
書き込まれていません。

## インストール

プログラミングの知識は不要です。1 行で済みます。

**macOS / Linux:**
```bash
curl -fsSL https://raw.githubusercontent.com/Coflazo/TCDD-Koltuk-Bul/main/install.sh | bash
```

**Windows (PowerShell):**
```powershell
irm https://raw.githubusercontent.com/Coflazo/TCDD-Koltuk-Bul/main/install.ps1 | iex
```

インストール先について。デスクトップで実行するとそこにフォルダを作ります。すでにデスクトップ
配下のフォルダにいる場合はその場に入れます。それ以外の場所からはデスクトップに移動します。
完了するとダブルクリックで起動できるファイルが残ります。macOS と Linux は
**Başlat.command**、Windows は **Baslat.bat** です。

## 使い方

1. 出発駅と到着駅を入力します。トルコ語の文字は不要で、打ち間違いも問題ありません。
   `sogutlucesme` で SÖĞÜTLÜÇEŞME が見つかり、`ankra` と打てば ANKARA を提案します。
2. 日付を入力します。複数でも構いません。融通が利くなら `17 18 21` と入力すれば 3 日とも
   監視します。
3. その日の全列車が、等級ごとの料金と空席数つきで表示されます。
4. 実際に乗ってもよい列車と等級を選びます。
5. あとは任せておけます。席を確保して知らせてくれます。支払いはご自身で行ってください。
