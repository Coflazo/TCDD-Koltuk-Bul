# TCDD Koltuk Bul

**Бот, который ловит освободившиеся места в распроданных турецких поездах и сразу их удерживает.**

Он снова и снова проверяет выбранные вами рейсы на сайте TCDD. Как только кто-то сдаёт
билет, бот выбирает место, запускает временное бронирование TCDD и звонит будильником,
пока вы не подойдёте к компьютеру.

Работает по всей сети, а не на одном направлении: 460 станций, оба направления, YHT,
Anahat и Bölgesel. Какие есть классы вагонов, он читает у самого поезда. Ничего из этого
не зашито в код.

## Установка

Программировать не нужно. Достаточно одной строки.

**macOS и Linux** (Терминал):
```bash
curl -fsSL https://raw.githubusercontent.com/Coflazo/TCDD-Koltuk-Bul/main/install.sh | bash
```

**Windows** (PowerShell):
```powershell
irm https://raw.githubusercontent.com/Coflazo/TCDD-Koltuk-Bul/main/install.ps1 | iex
```

Куда установится: если запустить на рабочем столе, создаст там папку. Если вы уже в папке
внутри рабочего стола, установится прямо там. Откуда угодно ещё, перейдёт на рабочий стол.
В конце останется файл для двойного щелчка: **Başlat.command** (macOS, Linux) или
**Baslat.bat** (Windows).

## Как пользоваться

1. Введите откуда и куда. Турецкие буквы необязательны, опечатки не страшны:
   `sogutlucesme` найдёт SÖĞÜTLÜÇEŞME, а на `ankra` он предложит ANKARA.
2. Какой день или дни. Если вы гибки, наберите `17 18 21`, и он следит за всеми тремя.
3. Он покажет все поезда этих дней с ценами и числом свободных мест по классам.
4. Выберите поезда и классы, которые вам подходят.
5. Дальше он сам. Удержит место и разбудит вас. Оплату вы делаете сами.

## Важно

- Только для личного пользования. Один пассажир, одно место. Не для перепродажи.
- Оплата никогда не автоматизируется. Данные карты не читаются, не хранятся и не вводятся.
- Места для колясок по умолчанию не отслеживаются, только если вы выберете их явно. Они
  существуют для пассажиров, которые не могут занять никакое другое место.
- Ваши данные остаются на вашем компьютере.
- Соблюдение условий использования TCDD, это ваша ответственность.
