**ბოტი, რომელიც იჭერს გათავისუფლებულ ადგილს გაყიდულ თურქულ მატარებლებში და მაშინვე იტოვებს.**

ის განუწყვეტლივ ამოწმებს თქვენს მიერ არჩეულ რეისებს TCDD-ის საიტზე. როგორც კი ვინმე
გააუქმებს ბილეთს, ბოტი ირჩევს ადგილს, იწყებს TCDD-ის დროებით ჯავშანს და რეკავს მანამ, სანამ
კომპიუტერთან არ მიხვალთ.

მუშაობს მთელ ქსელზე და არა ერთ მიმართულებაზე: 460 სადგური, ორივე მიმართულებით, YHT, Anahat
და Bölgesel. რომელი კლასებია, ამას თავად რეისიდან კითხულობს. არაფერი ამათგანი კოდში ჩაწერილი
არ არის.

## ინსტალაცია

პროგრამირების ცოდნა არ არის საჭირო. ერთი ხაზი საკმარისია.

**macOS / Linux:**
```bash
curl -fsSL https://raw.githubusercontent.com/Coflazo/TCDD-Koltuk-Bul/main/install.sh | bash
```

**Windows (PowerShell):**
```powershell
irm https://raw.githubusercontent.com/Coflazo/TCDD-Koltuk-Bul/main/install.ps1 | iex
```

სად დაინსტალირდება: თუ სამუშაო მაგიდაზე ხართ, იქ შექმნის საქაღალდეს. თუ უკვე სამუშაო მაგიდის
შიგნით არსებულ საქაღალდეში ხართ, იქვე დაინსტალირდება. სხვა ადგილიდან სამუშაო მაგიდაზე
გადავა. ბოლოს დარჩება ფაილი, რომელზეც ორჯერ დააწკაპუნებთ: **Başlat.command** (macOS, Linux)
ან **Baslat.bat** (Windows).

## როგორ გამოვიყენოთ

1. აკრიფეთ საიდან და სად. თურქული სიმბოლოები სავალდებულო არ არის და შეცდომებიც არაფერს
   შველის: `sogutlucesme` იპოვის SÖĞÜTLÜÇEŞME-ს, ხოლო `ankra`-ზე შემოგთავაზებთ ANKARA-ს.
2. რომელი დღე ან დღეები. თუ მოქნილი ხართ, აკრიფეთ `17 18 21` და სამივეს გააკონტროლებს.
3. გაჩვენებთ იმ დღეების ყველა მატარებელს ფასებით და თავისუფალი ადგილებით კლასების მიხედვით.
4. აირჩიეთ ის მატარებლები და კლასები, რომლითაც ნამდვილად იმგზავრებდით.
5. დანარჩენს თავად აკეთებს. დაიტოვებს ადგილს და გაგაღვიძებთ. გადახდას თქვენ აკეთებთ.
